# WONDER (Next.js 16 + Tailwind CSS 4)

WONDER — Interior Design Studio

WONDER is a contemporary interior design studio creating thoughtful, personal interiors shaped around the way people live. Our approach combines spatial planning, materials, furniture and considered details to create spaces with character, clarity and purpose.
This website introduces the studio and its philosophy through selected interior studies, material explorations and an overview of its services: Interior Design, Space Planning, Furniture & Materials, and Design Support. Visitors can explore the studio's visual direction, learn about its process and prepare a project enquiry.
The website is built with Next.js (App Router), React, TypeScript and Tailwind CSS 4. It features a responsive editorial layout, an interactive image gallery and a contact enquiry interface.
The interior studies shown on this website are conceptual imagery, not completed client projects. The enquiry form currently prepares a message for copying; it does not send submissions automatically.

## Стек

- Next.js 16, **App Router**, React 19, TypeScript (strict)
- Tailwind CSS 4 + `@tailwindcss/postcss`, **без `tailwind.config.js`**
- `next/image` для локальных WebP-фотографий
- Server Components для статичных секций, client components — только для интерактивности
- ESLint + TypeScript
